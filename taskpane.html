Co-Turns Excel Helper

Record numbering and confirmation · GitHub-hosted prototype 2.1

1. Identify contributor

Use your own unique initials. Numbering continues from the highest existing ID with those initials.

2. Create record

No active record

A new row is selected in Excel. Fill any desired fields in columns B–H, including the existing Class dropdowns.

3. Confirm or delete

Confirmation requires information in at least one field besides Record ID. Deleting clears columns B–H but keeps the ID permanently.

Designed for the fixed A–H Co-Turns columns. Geographical search is not yet implemented. This version handles IDs, confirmation, and deletions.
